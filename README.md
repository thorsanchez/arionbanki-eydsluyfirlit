# Hvað eyði ég?

Einfaldt web app til að greina bankaútgjöld frá Arion banka.

## Núverandi útlit

![skjamynd](/public/Screenshot%202026-01-08%20at%2014.16.12.png)
(er að nota mock data til prófunar)

## Um verkefnið

- Forrit sem les excel skrár frá arion og greinir útgjöld notenda.
- Hlaða upp bankayfirlit og fengið yfirlit yfir útgjöld, flokkanir og tölfræði.

## Tech stack

**Backend:**

- FastAPI
- Pandas fyrir data analysis
- Gemma 2 (a pc heima) fyrir ai flokkun á færslum

**Frontend:**

- React ogg TypeScript
- Vite
